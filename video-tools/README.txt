NetVibeMedia – יצירת שורט עם דיבוב בעברית (edge-tts)
=====================================================

הרצה:
    pip install -r requirements.txt
    python make_short.py

אפשרויות:
    --voice he-IL-AvriNeural   (גבר, ברירת מחדל)   או   he-IL-HilaNeural (אישה)
    --rate  +14%               מהירות דיבור (למשל +20% מהר יותר, -5% איטי יותר)
    --music 0.55               עוצמת הביט ברקע (0 = דיבוב בלבד)
    --out   path.mp4           קובץ יעד
    --no-voice                 בלי דיבוב (זמנים קבועים)

איך הסנכרון עובד:
    1. כל משפט בתסריט (SCRIPT בראש הקובץ) מופק כקובץ אודיו נפרד ע"י edge-tts.
    2. מודדים את משך הדיבור בפועל (אחרי חיתוך שתיקות בתחילה ובסוף).
    3. אורך כל סצנה = משך הדיבור שלה + רווחים. הסצנות מתארכות/מתקצרות לפי הקול.
    4. כל אנימציה (כותרת, כפתור, התראה) מתחילה בדיוק ברגע שהמשפט שלה מתחיל.
    5. הביט מונמך אוטומטית בזמן הדיבור, והאודיו משולב בתוך ה-mp4 הסופי.

לשינוי הטקסט: ערכו את SCRIPT בראש make_short.py (בלי מחירים), והריצו שוב.
הערה: edge-tts שולח את הטקסט לשירות הדיבוב של מיקרוסופט ולכן דורש חיבור לאינטרנט.
